# 分布式训练资源使用分析

## 观察到的现象

### 网络流量（PS Server）
- **峰值流入**: 18.7 GB (03:35)
- **典型流入**: 8-16 GB / 5分钟
- **总流量**: ~150+ GB / 训练周期

### 磁盘读取（PS Server）
- **EBS 读取**: 几乎为 0
- **仅有一次**: 348 KB (02:55)

## 为什么网络高但磁盘读写少？

### 1. **数据已预加载到内存**

数据文件在训练开始前已经分发到所有节点：
```
/home/ubuntu/easyrec_data/data/
├── ali_ccp_train_full.csv (2.5GB)
└── ali_ccp_test_full.csv (2.6GB)
```

**关键点**:
- 数据在容器启动时通过 `-v` 挂载到容器
- TensorFlow 的 `tf.data.Dataset` 会将数据缓存到内存
- 配置中的 `prefetch_size: 128` 和 `shuffle: true` 会预加载数据

### 2. **Parameter Server 架构的网络特性**

```
Workers (数据读取) → 计算梯度 → 网络传输 → PS Server (参数更新)
                                    ↓
                            参数同步回 Workers
```

**网络流量来源**:
1. **梯度上传**: 5个 Workers × 每步梯度 → PS Server
2. **参数下载**: PS Server → 5个 Workers 同步更新后的参数
3. **模型大小**: DeepFM 有大量 embedding 参数

**计算**:
- Embedding 参数: ~100K × 16维 × 7个特征 = ~11M 参数
- 每个参数 4 bytes (float32) = ~44 MB
- 每步需要传输: 梯度(上) + 参数(下) = ~88 MB
- 10000 步 × 88 MB = ~880 GB 理论值
- 实际 ~150 GB (有压缩和优化)

### 3. **为什么磁盘读取为 0？**

**原因**:
1. **数据在内存中**: 
   - 300MB 训练数据完全可以放入内存
   - `num_epochs: 10` 意味着重复使用内存中的数据
   
2. **Linux 页面缓存**:
   - 第一次读取后，数据被缓存在系统内存
   - 后续访问直接从内存读取，不触发磁盘 I/O
   
3. **Docker 卷挂载**:
   - 数据通过 bind mount 共享
   - 宿主机的页面缓存被容器共享

### 4. **验证数据加载**

检查 Worker 容器日志：
```bash
docker logs easyrec_worker_0 2>&1 | grep -i "data\|csv\|input"
```

应该看到：
- 数据文件路径: `/workspace/data/ali_ccp_train_full.csv`
- 数据加载成功的日志
- Batch 处理信息

## 资源使用优化建议

### 当前配置（已优化）

✅ **数据预分发**: 避免训练时从网络加载
✅ **内存缓存**: 小数据集完全在内存
✅ **Prefetch**: 异步数据加载
✅ **Shuffle**: 在内存中进行

### 如果使用更大数据集

对于 TB 级数据：
1. **使用 TFRecord 格式**: 更高效的二进制格式
2. **启用数据压缩**: 减少网络传输
3. **增加 prefetch_size**: 提高数据流水线效率
4. **考虑 S3/OSS**: 直接从对象存储读取

### 网络优化

当前网络使用是**正常且必要的**：
- Parameter Server 架构的固有特性
- 可以通过以下方式优化：
  1. **梯度压缩**: 减少传输量
  2. **本地 SGD**: 减少同步频率
  3. **混合精度训练**: FP16 减少一半传输量

## 总结

**观察到的现象是正常的**：

| 资源 | 使用情况 | 原因 |
|------|---------|------|
| 网络 | 高 (150GB+) | PS 架构需要频繁同步梯度和参数 |
| 磁盘 | 低 (~0) | 数据已在内存，Linux 页面缓存生效 |
| CPU | 中等 | 数据预处理和梯度计算 |
| 内存 | 中等 | 数据缓存 + 模型参数 |

**这是高效的训练配置**：
- 数据不需要重复从磁盘读取
- 网络用于必要的分布式通信
- 训练速度快（16分钟/10000步）
